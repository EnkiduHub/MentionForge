Support

Support for MentionForge API keys and subscriptions: lost key reissue, checking usage, billing portal cancellation, refunds, and contact.

Lost API key

Plaintext API keys (mfk_...) are shown once on the post-checkout claim page; only the SHA-256 hash is stored afterwards. Private requests: use the contact shown on this page when served by the Worker.

Check usage & cancel anytime

Check your current billing period and remaining quota at any time with GET /v1/keys/me:

curl -sS https://mentionforge.mentionforge.workers.dev/v1/keys/me \
  -H 'Authorization: Bearer YOUR_KEY'

Cancel anytime or update your payment method through the Stripe Billing Portal by calling POST /v1/keys/portal with your API key:

curl -sS -X POST https://mentionforge.mentionforge.workers.dev/v1/keys/portal \
  -H 'Authorization: Bearer YOUR_KEY'

Open the returned url in your browser to manage or cancel your subscription. If you no longer have your API key or cannot access the billing portal, contact support below with your checkout email and we will cancel it for you.

Cancellations & refunds

Cancelled subscriptions stop renewing and remain active until the end of the current billing period (period_end). Refund requests are handled case by case via support.

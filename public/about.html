About

About MentionForge: MIT-licensed agent social listening and brand research over REST and MCP, citing public news, web, and review sources.

What MentionForge is

MentionForge is a social listening and company/product research service for software agents and developers. It runs on Cloudflare Workers and exposes both a REST API (POST /v1/research and specialized lenses) and a Streamable HTTP Model Context Protocol server (/mcp, primary tool research_mentions).

For a brand, product, competitor, or topic query, MentionForge searches public sources — news (Google News RSS, GDELT, Hacker News), web (Wikipedia, Wikidata, and Brave Search when configured; plus GitHub Issues and Stack Overflow for developer queries), and review sites (via web search targeting Trustpilot, G2, and Capterra) — and returns structured volume, sentiment breakdown, themes, cited mentions, and an extractive summary.

Official Reddit and X API adapters are optional upgrades and are disabled by default (DISABLED_SOURCES=x,reddit). Live adapter status is published at GET /health.

How pricing and trials work

Discovery and grounding endpoints are free. Paid research calls cost $0.02 USDC per completed call on Base via the x402 payment standard, with 10 free trial calls per wallet via the X-Wallet header. Denied requests (such as rate-limit or quota errors) do not settle and are not charged.

Privacy policy

A plain-language account of what MentionForge stores, why, and for how long. No account or tracking cookies are needed to use the service.

On this page

  1. The short version
  2. Accounts, email, and payments
  3. What we store
  4. Metrics, caching, and rate limits
  5. On-chain payments are public
  6. Retention and data requests

The short version

  • Free tools, the free trial, and pay-per-call use need no account, sign-up, password, or tracking cookies.
  • We keep a small set of records to run the free trial, prevent double charges, enforce quotas, and count usage. Every one is listed below.
  • Payments made on-chain are public on the Base blockchain.
  • If you subscribe to an API key plan, Stripe handles your email address and card details. MentionForge never receives card numbers.

Accounts, email, and payments

Free trial and pay-per-call use need no account, sign-up, password, or tracking cookies. If you subscribe to an API key plan, Stripe (our payment processor) collects your email address and payment details under Stripe’s privacy policy. MentionForge does not receive card numbers. Stripe emails receipts and invoices to the subscriber.

What we store

MentionForge keeps the records below in Cloudflare D1, the database behind the service.

Free-trial usage trial_wallets

When you send the X-Wallet header to use the 10-call free trial, we store the wallet address in lowercase (wallet), how many trial calls it has used (used, up to 10), and when it was last updated (updated_at).

Double-charge protection idempotency

When a paid or trial call includes an Idempotency-Key header, we store the key, a SHA-256 hash of the canonical request body (body_hash), the status, the JSON response, billing details (amount_usdc, tx_hash, free_trial), and created_at. Entries expire after 24 hours and are deleted the next time they are looked up after expiry.

Daily totals stats_daily

Daily aggregate totals (day, calls, paid, usdc_micros, errors, trial). No wallet addresses, IP addresses, or raw query strings are stored in this table.

Quota counter x_id_usage

Daily counts (day, ids) of disclosed mention and post IDs over a rolling 30-day window, used to enforce the global 30-day quota.

In plain words: if you subscribe, we keep a fingerprint (hash) of your API key, your Stripe customer and subscription IDs, billing dates and how many calls you’ve used. We never see your card number.

API key records api_keys

If you subscribe to an API key plan, we store a SHA-256 hash of your API key (key_hash; the plain key is shown once on the claim page and is not retained after claim), your Stripe customer ID (stripe_customer_id), Stripe subscription ID (stripe_subscription_id), plan status (status), billing-period dates (period_start, period_end), when the record was created (created_at), the Checkout session ID (checkout_session_id), whether the key has been claimed (claimed), and a temporary pending_key that is cleared after claim.

Plan usage plan_usage

Per-key usage counts for your quota: the API key hash (key_hash), the billing period start (period_start), and calls used in that period (calls).

Billing event log stripe_events

Stripe webhook event IDs (event_id) and when they arrived (received_at), so the same Stripe event is never applied twice. This table does not store email addresses or card numbers.

Metrics, caching, and rate limits

Usage metrics (Cloudflare Analytics Engine, METRICS): for each completed or failed research call we record the event type (paid, trial, or error), the UTC date, a SHA-256 hash of the normalized query (never the raw query text), a count of 1, and usdc_micros.

Response caching (Cloudflare Cache API): research results, without billing details, request_id, or latency, are cached by a SHA-256 hash of the query parameters for 10 minutes (24h timeframe), 30 minutes (7d timeframe), or 2 hours (30d or custom timeframe).

Rate limits and logs: rate limits are counted per wallet address (paid and trial requests) or per client IP address (cf-connecting-ip, for unpaid and discovery requests) over 60-second windows. Operational logs record request_id and status codes and never record payment signatures or secrets.

On-chain payments are public

Paid calls settle $0.02 USDC per call on the Base blockchain through an x402 payment facilitator. Blockchain transactions, wallet addresses, and transaction hashes (tx_hash) are permanently public on Base.

Retention and data requests

Rows in api_keys and plan_usage are kept while the subscription exists and afterwards until you ask us to delete them via Support. MentionForge does not automatically delete those rows when a subscription ends. Stripe keeps its own payment records under its policy; deleting our rows does not delete Stripe’s.

Private requests (access or deletion): email harbor-ops@mail.grokbot.com.

Questions or bug reports: https://github.com/EnkiduHub/MentionForge/issues.

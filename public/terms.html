Terms

Plain-language terms for using the MentionForge REST API and MCP server: as-is service, $0.02 USDC x402 settlement, 10-call wallet trial, API key subscription.

Service provided as-is

MentionForge is provided “AS IS” and “AS AVAILABLE” without warranties of any kind, express or implied, including accuracy, completeness, availability, or fitness for a particular purpose.

Responses aggregate snippets and links from public sources such as news (Google News RSS, GDELT, Hacker News), web sources (Wikipedia, Wikidata, and Brave Search when configured), and review sites. Do not use MentionForge for live trading execution or automated high-stakes decisions without human review.

Pricing, free trial, and on-chain finality

Free discovery and grounding endpoints (GET /health, GET /v1/pricing, GET /v1/research/example, GET /v1/entity, GET /v1/suggest) cost $0.

Each wallet address receives 10 free trial calls shared across paid research endpoints and MCP tools by sending the X-Wallet header.

Paid calls cost $0.02 USDC per call on Base (or Base Sepolia on staging) via the x402 payment protocol (PAYMENT-SIGNATURE header) and settle on-chain through the configured facilitator. Once an on-chain payment settles, the blockchain transaction is final and irreversible.

Nothing is charged when a request is denied before settlement (for example validation errors, rate limits, upstream source failures, or rolling quota limits). Replaying the same request body with the same Idempotency-Key within 24 hours returns the stored response without charging again.

Rate limits and acceptable use

Requests are subject to per-minute rate limits (HTTP 429 with Retry-After) and a rolling 30-day disclosed-ID quota. Do not flood endpoints or attempt to bypass rate limits or payment verification.

API key subscription

An API key subscription is a monthly subscription billed in advance by Stripe. It renews automatically until cancelled. Each billing period includes a quota of 1,500 research calls. The price and billing interval are shown at Stripe Checkout before you pay.

Cancel anytime via the Stripe billing portal (POST /v1/keys/portal) or /support. Cancellation takes effect at the end of the current billing period; you keep access until then. There are no pro-rated refunds by default. Refund requests are reviewed case by case via /support.

If a renewal payment fails, access continues until the end of the current billing period, then stops until payment succeeds.

Your API key is shown once. Keep it safe.

When your 1,500 calls for the billing period are used up, further key requests are denied until the next billing period, and nothing is charged. The service’s global rate limits and rolling 30-day ID quota also apply to key plans.

Keys may be revoked for abuse. The service is provided as-is.

How it works

From question to cited answer in one call

No dashboards to set up and no scrapers to babysit. Your agent asks, MentionForge does the research, and you pay only for completed calls.

  1. 01

    Ask a question

    Ask about a brand, product, competitor, or topic from an MCP-compatible AI agent (research_mentions) or straight from your code with the REST API (POST /v1/research).

  2. 02

    We search public sources

    MentionForge searches news, Wikipedia, Wikidata, Brave web search, and review sites, then returns sentiment, themes, and cited mentions in one structured response.

  3. 03

    Pay $0.02 per completed call

    The first 10 paid calls per wallet are free with the X-Wallet header. After that, each completed call costs $0.02 in USDC on Base via x402. Denied requests are not charged.

Worked cost: first 10 calls per wallet = $0.00 · 100 calls = $2.00 · 1,000 calls = $20.00.

What you get

Everything an agent needs to answer “what are people saying?”

All paid tools are built on the same research pass, so each returns a consistent, structured view of the same cited evidence.

  • Cited mentions, not guesses

    Every mention carries its URL, author, timestamp, engagement, and sentiment, plus a citation list your agent can quote. Weight sources, not vibes.

  • Volume & trend

    Total mentions, a split by source, and time-bucketed counts for the window you choose.

  • Sentiment mix

    Positive, neutral, and negative shares plus an overall score, with a per-source breakdown.

  • Themes

    The recurring topics in the conversation, each with example snippets.

  • Share of voice

    Your brand against up to two competitors, by mentions and engagement.

  • Risk signals

    Early warning for volume spikes and concentrated negative sentiment, with the reasons spelled out.

  • Built for agents and automation

    Predictable JSON with a summary, confidence, freshness, and request ID. Send an Idempotency-Key and a retry of the same request within 24 hours returns the stored response without charging again. Quiet weeks get a clear answer, not an error.

Quickstart

Connect in under a minute

Point any MCP client at the hosted server, or call the REST API directly. Start with the free get_example or suggest_tool to see the shape of a response.

Cursor, VS Code & other MCP clients

Add this to your client’s mcp.json:

{
  "mcpServers": {
    "mentionforge": {
      "url": "https://mentionforge.mentionforge.workers.dev/mcp"
    }
  }
}

Claude Code

One command adds the hosted server:

claude mcp add --transport http mentionforge https://mentionforge.mentionforge.workers.dev/mcp

Then ask: “Use MentionForge to research what people are saying about Cloudflare Workers this week.”

REST API: POST, 402, retry

Query builder

Presets only fill in these examples. Nothing is sent or charged from this page.

curl -sS -X POST https://mentionforge.mentionforge.workers.dev/v1/research \
  -H 'content-type: application/json' \
  -H 'Idempotency-Key: (new UUID per unique body)' \
  -d '{"query":"Cloudflare Workers","timeframe":"7d","limit":20,"include_summary":true}'
# HTTP 402 → retry with PAYMENT-SIGNATURE (0.02 USDC on Base)
# Free trial → add -H 'X-Wallet: (your wallet address)'

How paying per call works

  1. Call a paid endpoint. Without payment you get HTTP 402 with the exact amount, network, and a ready-to-run retry hint.
  2. Sign a $0.02 USDC payment on Base with any x402-capable wallet or SDK.
  3. Retry with PAYMENT-SIGNATURE. You get the result plus a receipt in meta.billing.

Settle 0.02 USDC on Base. Agents read the payment address (payTo) from GET /v1/pricing.

Trying it out? Send X-Wallet with your wallet address for 10 free paid calls. Always send an Idempotency-Key so retries are never charged twice.

FAQ

Frequently asked questions

Still curious? Read the agent install guide or ask on GitHub.

Is there a free way to try it?

Yes. Five tools never charge: get_health, get_pricing, get_example, suggest_tool, and get_entity_profile. Paid tools include 10 free trial calls per wallet, shared across all paid tools.

What does a paid call cost?

$0.02 USDC per successful paid call on Base. Every paid tool costs the same, whether you call it over REST or MCP.

Do I need an account or an API key?

No. Paid calls use x402: your agent or code attaches a payment signature to the request, so there is nothing to sign up for. For the free trial, send your wallet address in the X-Wallet header.

What am I charged for?

Successful research calls, including cached results and time windows with no mentions, because “no mentions in 7 days” is a real answer. You are never charged for free tools, trial calls, requests denied before settlement (such as validation errors, rate limits, upstream source failures, or quota limits), or replays of the same Idempotency-Key within 24 hours.

Which sources does it search?

News (Google News RSS, GDELT, Hacker News), the web (Wikipedia, Wikidata, Brave Search, plus GitHub Issues and Stack Overflow for developer topics), and review sites (Trustpilot, G2, and Capterra via web search). Native Reddit and X feeds are off by default. Live status is always at GET /health.

Can I see the output before paying?

Yes. Call the free get_example tool or GET /v1/research/example for a real, frozen Cloudflare Workers result. Its billing amount is $0.

Does draft_reply post anything?

No. draft_reply drafts unsent public-reply copy from cited mentions for you to review. It never posts.

Which clients does it work with?

Any MCP client that supports Streamable HTTP, including Claude Code, Cursor, and VS Code, and any HTTP client through the REST API documented in OpenAPI.

Is MentionForge open source?

Yes. The source code is MIT-licensed on GitHub. The hosted service on this site is the paid product, and the MentionForge name and logo are covered by its trademark policy.
